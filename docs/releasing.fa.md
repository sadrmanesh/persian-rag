# انتشار نسخه

انتشار با برچسب گیت انجام می شود. با فرستادن برچسبی مانند `v0.2.0`، گردش کار `Release` اجرا می شود:

1. **ساخت**: بررسی می شود که برچسب با نسخه `pyproject.toml` یکی باشد، سپس بسته ها ساخته و با `twine check` بررسی می شوند.
2. **انتشار**: بسته ها با یکی از دو روش زیر در PyPI منتشر می شوند.

| روش | آماده سازی |
| --- | --- |
| انتشار مورد اعتماد (پیشنهادی) | در PyPI یک ناشر مورد اعتماد برای این مخزن با گردش کار `release.yml` و محیط `pypi` تعریف کنید و متغیر `PYPI_TRUSTED_PUBLISHING` را برابر `true` قرار دهید. |
| توکن API | راز `PYPI_API_TOKEN` را در مخزن تعریف کنید. |

اگر هیچ کدام تنظیم نشده باشد، ساخت انجام می شود اما انتشار با یک پیام اطلاع رسانی رد می شود.

## فهرست کارها

1. نسخه را در `pyproject.toml` و `src/persian_rag/version.py` به روز کنید.
2. بخش تازه ای به `CHANGELOG.md` اضافه کنید.
3. تغییرات را با CI سبز در شاخه `main` ادغام کنید.
4. برچسب بزنید و بفرستید: `git tag v0.2.0 && git push origin v0.2.0`
